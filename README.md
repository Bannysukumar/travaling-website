## Overview

A modern, responsive travel booking website with an admin panel for managing bookings, users, and travel packages.


What is actually in the repository: `admin/`, `css/`, `js/`, `translations/`. GitHub reports the primary language as HTML.

Published site recorded on the repository: https://travaling-website.vercel.app

## Features


- User authentication (signup/login)
- Flight booking
- Hotel booking
- Tour booking
- Admin panel for managing:
- Responsive design for all devices
- Real-time updates using Firebase
- Secure payment integration with UPI
